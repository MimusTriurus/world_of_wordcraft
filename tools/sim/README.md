# Симулятор забега

Считает кривую сложности рогалик-режима на модельном игроке. Не пересказывает
игру, а поднимает настоящий скрипт из `word-shooter.html` в Node: физика,
спавн, `blockCost`, бюджет поля и пул слов — те самые. Подменяется только
`rules()`, чтобы правила задавала лестница волн, а не таблица `LEVELS`.

Числа, которые он выдал, лежат в [../../docs/roguelite.md](../../docs/roguelite.md).

## Запуск

Разбор одного забега по волнам — бюджет, сид, темп игрока:

```bash
node tools/sim/detail.mjs 6 2.2 1 1
```

Калибровка: свип кривой бюджета и проходимость по классам игроков.

```bash
node tools/sim/final.mjs 6 2.2
```

## Что где

- `harness.mjs` — заглушки DOM, детерминированный `Math.random`, экспорт
  внутренностей игры наружу
- `sim.mjs` — лестница осей, профили волн, модельный игрок
- `detail.mjs`, `final.mjs` — гонялки

Симулятор читает игру текстом и патчит две точки: сигнатуру `rules()` и хвост
`requestAnimationFrame(frame);`. Если переименовать их в игре, `boot()` упадёт
с внятной ошибкой, а не тихо соврёт.
