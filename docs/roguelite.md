# Перевод Word Shooter на рогалик-рельсы

Предложение по мета-игре и пересмотру геймплея. Написано поверх текущего
состояния `word-shooter.html` (волн нет, лестница уровней `LEVELS[]`,
бюджет внимания `fieldLoad`, модификаторы в меню).

## Главная мысль

Соблазн очевидный: навесить «+1 ствол, +скорострельность, бомба на три
клетки». Но у игры есть системная особенность, которая такой подход ломает:
**сложность саморегулируется бюджетом внимания** (`fieldLoad` / `blockCost` /
`load`). Если дать игроку прямую силу, поле просто станет пустее — игра станет
строго легче, и рогалик выродится в снежный ком без сопротивления.

Отсюда правило дизайна в основе всего:

> Апгрейд не добавляет силы — он **переносит давление с одной оси на другую**.
> Осей четыре, и они уже описаны в коде: длина слова, редкость, количество
> пропусков, скорость падения. Плюс пятая, метагеймовая: **словарь самого
> игрока**.

Второе, что делает игру не «ещё одним рогаликом»: уникальный ресурс здесь —
не патроны, а **знание слов**. Метапрогрессию нужно строить именно на нём.

## 1. Структура забега

Сейчас: бесконечная лестница, `WORDS_PER_LEVEL = 8` → `levelUp()`. Ровная
кривая без пауз, а рогалику нужны точки выбора.

**Волны вместо уровней.** Волна = квота слов (10–12). Поле дочищается,
падение стопорится, экран выбора: **три карты, берёшь одну**. Три волны —
сектор, в конце сектора «стена» (босс). Забег ~12 волн, 12–15 минут: при
замеренных 1,2–5 с на слово это 150–350 слов.

`LEVELS[]` остаётся, но перестаёт быть «что происходит сейчас» и становится
**базой, поверх которой апгрейды и проклятия двигают отдельные оси**.
`rules()` из чистой таблицы превращается в `base + сумма модификаторов забега`.

## 2. Модули — внутризабеговые апгрейды

Всё цепляется к уже написанному коду, строить с нуля ничего не нужно.

### Ствол — `flyShot`, `MAX_SHOTS`, `SHOT_COOLDOWN`

| Модуль | Что делает |
| --- | --- |
| Рикошет | Не подошедшая буква не даёт страйк, а летит дальше в блок выше |
| Бронебойная | Снаряд проходит блок насквозь. Силён с прицелом, бесполезен без |
| Второй ствол | Два выстрела подряд без кулдауна |

### Заряды — `detonate`, `CLEAR_COST`, `bombs`

| Модуль | Что делает |
| --- | --- |
| Стабилизатор | Точечный подрыв ЛКМ **не сбрасывает комбо**. Самый «билдовый» апгрейд: разворачивает всю экономику забега |
| Сканер | Заряд не сносит блок, а **открывает одну букву** (см. риски) |
| Ёмкость / темп | Больше зарядов в запасе, чаще начисление (сейчас +1 за 10 слов) |

### Словарь — `eligible`, `neighboursOf`, `rules().rank`

| Модуль | Что делает |
| --- | --- |
| Синонимы | `neighboursOf(word, maxGaps + 1)` — засчитывается больше букв, слово прощает почти-угадывание |
| Эрудит | `rank` вверх (слова реже) в обмен на множитель очков. Классический риск/награда, ручка уже параметризована |
| Тематика | Сдвиг пула: природа / техника / еда. Снаружи флейвор, внутри фильтр по списку |

### Комбо — `solve`, `miss`

| Модуль | Что делает |
| --- | --- |
| Щит комбо | Один промах не обнуляет |
| Снятие потолка | Убирает `Math.min(..., 5)` у множителя |

### Поле — `DANGER_Y`, `load`

| Модуль | Что делает |
| --- | --- |
| Опущенная линия | `DANGER_Y` ниже — больше времени на блок |
| Торможение | Блок замедляется при попадании верной буквы |

## 3. Проклятия и пакты

`mods` (`aim`, `verbs`, `adjs`) сейчас — экран настроек. **Его стоит
превратить в пул проклятий.** Прицел по букве, глаголы, прилагательные, второй
пропуск, порча слова с *первого* промаха — это готовые, уже реализованные
ручки сложности.

Пакт: «возьми проклятие — получишь карту редкого тира». Настройки перестают
быть настройками и становятся содержанием игры.

## 4. Метапрогрессия: лексикон

Между забегами копится **личный словарь**: каждое собранное слово
записывается навсегда. Экран-словарь, который заполняется, — для словесной
игры самый липкий крючок из возможных и дешевле любого дерева талантов.

Важная оговорка: **лексикон не должен давать силу**. Собранные слова не
становятся легче, иначе игра наказывает за прогресс. Он открывает *опции*:
новые модули в пул, темы, стартовые пакты, восхождения — старт с проклятием
ради множителя.

Отдельно расходная валюта («чернила») за забег: стартовые заряды,
разблокировка модулей, тиры восхождения.

## 5. Босс

«Стена»: один широкий блок, длинное слово, три-четыре пропуска, падает
медленно, **ЛКМ его не берёт**, бомба сносит только один сегмент.
Единственный выход — реально собрать слово. Использует ровно то, что уже
написано, а ощущается как совершенно другой момент.

## Риски

1. **Сканер-подсказка — прямая замена знанию.** Он же будет самой ценной
   картой в игре и обесценит остальные. Держать редким и дорогим либо не
   вводить вовсе.
2. **Экраны выбора нагружают ту же мышцу, что и геймплей** — чтение. Карта =
   иконка плюс одна строка, три штуки, без описаний абзацем. Иначе усталость.
3. **Бюджет поля должен расти по волнам независимо от апгрейдов**, иначе см.
   главную мысль.
4. **Красный уже занят** испорченным словом. Для карт и подсветки редкости
   придётся обходиться штриховкой и рамками: монохром экономит цвет жёстко.
5. Забег на 15 минут при трёх жизнях — смерть на двенадцатой волне будет
   ощущаться дорого. Возможно, жизни стоит сделать покупаемым ресурсом, а не
   фиксированной тройкой.

## Порядок работ

MVP на один-два подхода:

1. Волны и экран выбора трёх карт — каркас, без него ничего не проверить
2. Восемь-десять модулей: по два из каждой группы, обязательно *Стабилизатор*
   и *Эрудит*
3. Пакты-проклятия из уже готовых `mods`
4. Счётчик лексикона в `localStorage`: число и список, без экрана коллекции

Следующим слоем: босс, темы, чернила, восхождения.
